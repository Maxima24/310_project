# --- Camera (--type camera --real) -----------------------------------------
#
# WHEEL WARNING: opencv-python-headless usually lags the newest CPython by
# several months, and this repo's dev machine runs Python 3.14 — pip may fall
# back to a source build needing CMake and a C++ toolchain.
#
# Options, cheapest first:
#   1. Run the camera agent in Docker — agents/Dockerfile pins python:3.12-slim.
#   2. Make a 3.12/3.13 virtualenv just for the camera agent.
#   3. Build from source (slow, needs CMake).
#
# None of this affects simulation mode: cv2 is imported lazily, so an agent that
# never uses --real never touches OpenCV.
opencv-python-headless>=4.10

# "HARDWARE STUB". Two commented lines per class.
